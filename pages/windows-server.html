Windows Server

Installation, Konfiguration und Administration

Erweiterte Befehls- und Themenreferenz: Alle zusätzlichen Befehle, Parameter, Praxisbeispiele und Diagnose öffnen →
Grundlagen

Aufgaben und typische Rollen

Windows Server stellt zentrale Dienste für Benutzer, Computer und Anwendungen bereit. Eine Serverrolle erweitert das System um eine bestimmte Funktion.

  • Active Directory Domain Services (AD DS): zentrale Identitäts- und Computerverwaltung.
  • DNS Server: Namensauflösung für Hosts und Dienste.
  • DHCP Server: automatische Vergabe von IP-Konfigurationen.
  • File and Storage Services: Dateifreigaben und Speicherverwaltung.
  • Hyper-V: Betrieb virtueller Maschinen.
  • Web Server (IIS): Bereitstellung von Webanwendungen.
  • Remote Desktop Services: zentrale Remotedesktop- und Sitzungshostdienste.
Installiere nur Rollen und Features, die der Server tatsächlich benötigt. Weniger installierte Komponenten reduzieren Wartungsaufwand und Angriffsfläche.
Planung

Vor der Installation

  • Serverzweck und benötigte Rollen festlegen.
  • Hardware beziehungsweise VM-Ressourcen planen: CPU, RAM, Datenträger und Netzwerk.
  • Edition und Installationsoption auswählen: Desktop Experience oder Server Core.
  • Servername, IP-Plan, DNS, Gateway und Zeitzone dokumentieren.
  • Speicherbedarf, Backup, Monitoring und Wiederherstellung berücksichtigen.

Server Core hat keine lokale grafische Desktopoberfläche und wird überwiegend per PowerShell, Eingabeaufforderung und Remoteverwaltung administriert. Es benötigt in der Regel weniger Ressourcen und hat eine kleinere lokale Angriffsfläche.

Erstkonfiguration

Checkliste nach der Installation

  1. Computername setzen und Neustart durchführen.
  2. IP-Adresse, Subnetz, Gateway und DNS korrekt konfigurieren.
  3. Zeitzone und Zeitsynchronisierung prüfen.
  4. Windows Updates installieren und Neustarts abschließen.
  5. Nur benötigte Rollen und Features installieren.
  6. Firewall und Remoteverwaltung gezielt konfigurieren.
  7. Administratorkonten und Berechtigungen überprüfen.
  8. Backup, Monitoring und Protokollierung einrichten.
  9. Konfiguration und Wiederherstellungsweg dokumentieren.
PowerShell

Systeminformationen und Erstkonfiguration

# Systeminformationen
Get-ComputerInfo
hostname
Get-TimeZone
Get-NetIPConfiguration

# Computername ändern (Neustart erforderlich)
Rename-Computer -NewName "SRV01" -Restart

# Rollen und Features anzeigen
Get-WindowsFeature

# Beispiel: DNS-Serverrolle installieren
Install-WindowsFeature -Name DNS -IncludeManagementTools
Beispielnamen wie SRV01 und Netzwerkkonfigurationen vor der Verwendung an die eigene Umgebung anpassen. Änderungen an produktiven Servern vorher planen.
Netzwerk

IP-Konfiguration prüfen

Server mit festen Infrastrukturaufgaben verwenden häufig eine dokumentierte statische IP-Adresse. In Domänenumgebungen muss insbesondere die DNS-Konfiguration stimmen.

# Konfiguration anzeigen
ipconfig /all
Get-NetIPConfiguration
Get-DnsClientServerAddress

# Erreichbarkeit und Namensauflösung testen
ping 192.168.1.1
Resolve-DnsName server.example.local
Test-NetConnection server.example.local -Port 445

# Routingtabelle anzeigen
route print
Get-NetRoute

Eine erfolgreiche IP-Verbindung beweist nicht automatisch, dass DNS, Firewall oder der benötigte Anwendungsdienst funktionieren.

Rollen & Features

Rollen verwalten

# Installierte Rollen und Features
Get-WindowsFeature | Where-Object InstallState -eq "Installed"

# Verfügbare Rollen suchen
Get-WindowsFeature *File*
Get-WindowsFeature *Web*

# Beispiel: File-Server-Rolle installieren
Install-WindowsFeature -Name FS-FileServer -IncludeManagementTools

# Beispiel: Rolle entfernen
Uninstall-WindowsFeature -Name FS-FileServer

Für die grafische Verwaltung kann der Server-Manager verwendet werden. Viele Rollen lassen sich zusätzlich mit PowerShell verwalten.

Dateidienste

Freigaben und NTFS-Berechtigungen

Bei Windows-Dateifreigaben wirken Freigabeberechtigungen und NTFS-Berechtigungen zusammen. Der tatsächlich mögliche Zugriff ergibt sich aus beiden Berechtigungsebenen.

# Freigaben anzeigen
Get-SmbShare

# Beispiel: Freigabe erstellen
New-SmbShare -Name "Daten" -Path "D:\Daten" -FullAccess "CONTOSO\FileAdmins"

# Freigabeberechtigungen anzeigen
Get-SmbShareAccess -Name "Daten"

# NTFS-Berechtigungen anzeigen
Get-Acl "D:\Daten" | Format-List
Berechtigungen nach dem Least-Privilege-Prinzip vergeben. Für den produktiven Einsatz Gruppen statt einzelner Benutzer verwenden und Zugriffe testen.
Dienste

Windows-Dienste verwalten

# Dienste auflisten
Get-Service

# Bestimmten Dienst suchen und prüfen
Get-Service -Name Spooler

# Dienst starten, stoppen oder neu starten
Start-Service -Name Spooler
Stop-Service -Name Spooler
Restart-Service -Name Spooler

# Starttyp anzeigen
Get-CimInstance Win32_Service |
  Select-Object Name, State, StartMode

Vor einem Neustart eines Dienstes prüfen, welche Anwendungen davon abhängig sind und ob eine Unterbrechung Auswirkungen hat.

Remoteverwaltung

RDP und PowerShell-Remoting

  • Remote Desktop (RDP) ermöglicht eine grafische Sitzung; Standardport ist TCP 3389.
  • PowerShell-Remoting verwendet typischerweise WinRM; Standardports sind TCP 5985 (HTTP) und 5986 (HTTPS).
  • Remotezugriff auf erforderliche Admin-Systeme und Quellnetze begrenzen.
  • MFA und geeignete sichere Zugangswege verwenden, sofern verfügbar.
# WinRM-Konfiguration prüfen
winrm quickconfig
winrm enumerate winrm/config/listener

# Verbindung testen
Test-WSMan SRV01

# Remote-PowerShell-Sitzung öffnen
Enter-PSSession -ComputerName SRV01

# Sitzung beenden
Exit-PSSession
WinRM nicht ungeschützt ins Internet veröffentlichen. Für produktive Umgebungen sichere Authentifizierung, Zertifikate beziehungsweise Kerberos und Firewallregeln passend zur Domänen- und Netzwerkarchitektur konfigurieren.
Updates

Windows Updates und Wartung

  • Updates zunächst in einer Testumgebung oder Pilotgruppe prüfen.
  • Wartungsfenster und mögliche Neustarts einplanen.
  • Vor kritischen Änderungen den Backup-Status prüfen.
  • Nach Updates Dienste, Anwendungen und Ereignisprotokolle kontrollieren.
  • Installationsstand und bekannte Probleme dokumentieren.
# Betriebssystemversion und Build
Get-ComputerInfo |
  Select-Object WindowsProductName, WindowsVersion, OsBuildNumber

# Letzte Hotfixes anzeigen
Get-HotFix | Sort-Object InstalledOn -Descending
Monitoring & Logs

Ereignisanzeige und Systemzustand

Die Ereignisanzeige hilft, Fehler zeitlich einzugrenzen. Besonders wichtig sind die Protokolle System, Anwendung und – bei Domänen- oder Sicherheitsproblemen – passende Spezialprotokolle.

# Letzte Systemfehler anzeigen
Get-WinEvent -FilterHashtable @{
  LogName = 'System'
  Level = 2
} -MaxEvents 20

# Letzte Anwendungsfehler anzeigen
Get-WinEvent -FilterHashtable @{
  LogName = 'Application'
  Level = 2
} -MaxEvents 20

# Speicherplatz prüfen
Get-Volume
Get-PSDrive -PSProvider FileSystem

# CPU- und Speicherauslastung (Momentaufnahme)
Get-Counter '\Processor(_Total)\% Processor Time'
Get-Counter '\Memory\Available MBytes'
Sicherheit

Basis-Hardening

  • Sicherheitsupdates zeitnah und kontrolliert installieren.
  • Separate Administratorkonten nutzen und privilegierte Rechte begrenzen.
  • MFA für administrative Zugänge einsetzen, wo möglich.
  • Firewall aktiv lassen und nur notwendige Verbindungen erlauben.
  • Unnötige Rollen, Dienste und lokale Konten entfernen oder deaktivieren.
  • RDP und WinRM nur für autorisierte Systeme und Netze freigeben.
  • Audit- und Sicherheitsprotokolle zentral sammeln und überwachen.
  • Backups vor Manipulation schützen und Wiederherstellung testen.
Troubleshooting

Häufige Fehler systematisch prüfen

ProblemErste PrüfungHilfreiche Befehle
Server nicht erreichbarIP, Gateway, VLAN, Firewall und Link prüfenipconfig /all, ping, Test-NetConnection
Namensauflösung fehlerhaftDNS-Server und DNS-Einträge prüfennslookup, Resolve-DnsName
Dienst startet nichtAbhängigkeiten und Ereignisprotokoll prüfenGet-Service, Get-WinEvent
Freigabe nicht erreichbarNetzwerk, SMB-Port und Berechtigungen prüfenTest-NetConnection -Port 445, Get-SmbShareAccess
Wenig SpeicherplatzVolume und große Verzeichnisse ermittelnGet-Volume, Get-ChildItem
Systemdateien beschädigtKomponentenstore und Systemdateien prüfenDISM, sfc /scannow
# Komponentenstore prüfen und reparieren
DISM /Online /Cleanup-Image /RestoreHealth

# Geschützte Systemdateien prüfen
sfc /scannow

Bei Fehlern zuerst Zeitstempel, betroffene Systeme, letzte Änderungen und genaue Fehlermeldungen erfassen. Immer nur eine Änderung gleichzeitig testen.

Backup & Recovery

Backup-Grundregeln

  • Systemstatus und wichtige Daten entsprechend der Wiederherstellungsanforderungen sichern.
  • Aufbewahrungsfristen, RPO und RTO festlegen.
  • Backups getrennt vom Produktivsystem speichern und Zugriffe absichern.
  • Erfolgreiche Backup-Jobs überwachen.
  • Wiederherstellung regelmäßig praktisch testen und dokumentieren.
Ein erfolgreicher Backup-Job allein reicht nicht: Erst ein getesteter Restore zeigt, ob Daten und Systeme wiederhergestellt werden können.
