Empfohlene Reihenfolge zum Lernen

Für einen sicheren Einstieg empfehlen wir: Grundlagen → virtuelle Maschinen → LXC → Netzwerk → Storage → Backup → Sicherheit → Cluster → HA → SDN/Ceph → Automatisierung.

Produktionshinweis: Änderungen an Storage, Netzwerk, Cluster, Firewall oder Passthrough können den Host oder Datenbestand beeinträchtigen. Vorher Backup, Wartungsfenster, Konsolenzugriff und Rückfallplan sicherstellen.
