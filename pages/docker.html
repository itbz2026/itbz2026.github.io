Docker

Container und Compose

Konzepte

Docker-Grundbegriffe

  • Image: Vorlage zum Erstellen eines Containers.
  • Container: gestartete Instanz eines Images.
  • Volume: persistenter Speicher für Containerdaten.
  • Network: verbindet Container miteinander.
  • Compose: beschreibt mehrere Services in einer YAML-Datei.
Befehle

Docker im Alltag

docker ps
docker ps -a
docker images
docker logs -f CONTAINER
docker compose up -d
docker compose down
docker compose ps
docker stats
Persistente Daten in Volumes oder Host-Verzeichnissen speichern. Vor Updates Daten sichern und Release Notes prüfen.
