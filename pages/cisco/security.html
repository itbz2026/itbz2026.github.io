Cisco Network Security

ACL · Port Security · DHCP Snooping · DAI · IP Source Guard

ACL

Standard- und Extended ACL

! Standard ACL – Quellnetz erlauben
access-list 10 permit 192.168.10.0 0.0.0.255
access-list 10 deny any
interface vlan 20
 ip access-group 10 in

! Named Extended ACL
ip access-list extended USERS-TO-SERVER
 permit tcp 192.168.10.0 0.0.0.255 host 192.168.20.10 eq 443
 deny ip any any
interface vlan 20
 ip access-group USERS-TO-SERVER out

show access-lists
show ip interface vlan 20
ACLs besitzen am Ende eine implizite deny-Regel. Richtung und Platzierung sorgfältig planen, sonst kann legitimer Verkehr blockiert werden.
Port Security

MAC-Adressen auf Access-Port begrenzen

interface gigabitEthernet 1/0/10
 switchport mode access
 switchport access vlan 10
 switchport port-security
 switchport port-security maximum 2
 switchport port-security mac-address sticky
 switchport port-security violation restrict
show port-security
show port-security interface gi1/0/10

Violation-Modi umfassen je nach Plattform protect, restrict und shutdown. Sticky MAC-Adressen werden in die laufende Konfiguration übernommen.

DHCP Snooping

Unerlaubte DHCP-Server verhindern

ip dhcp snooping
ip dhcp snooping vlan 10,20
interface gigabitEthernet 1/0/48
 description Trusted-Uplink
 ip dhcp snooping trust
interface range gigabitEthernet 1/0/1-24
 ip dhcp snooping limit rate 15
show ip dhcp snooping
show ip dhcp snooping binding

Client-Ports bleiben untrusted. Trust nur in Richtung legitimer DHCP-Server oder Relay setzen.

Dynamic ARP Inspection

ARP-Spoofing erschweren

ip arp inspection vlan 10,20
interface gigabitEthernet 1/0/48
 ip arp inspection trust
interface range gigabitEthernet 1/0/1-24
 ip arp inspection limit rate 15
show ip arp inspection
show ip arp inspection interfaces
show ip arp inspection statistics

DAI nutzt DHCP-Snooping-Bindings. Für statisch adressierte Geräte können ARP-ACLs erforderlich sein.

IP Source Guard

IP-Spoofing auf Access-Ports begrenzen

interface gigabitEthernet 1/0/10
 switchport mode access
 switchport access vlan 10
 ip verify source
show ip verify source
show ip dhcp snooping binding

Für statische Endgeräte passende statische Bindings planen. Funktionen sind plattformabhängig.

Hardening

Management-Zugriff absichern

configure terminal
ip domain-name lab.example
username netadmin privilege 15 secret CHANGE-ME
crypto key generate rsa modulus 2048
ip ssh version 2
line vty 0 15
 login local
 transport input ssh
 exec-timeout 10 0
end
show ip ssh
show users

Zusätzlich Management-VLAN, AAA/TACACS+/RADIUS, restriktive Management-ACLs, sichere SNMP-Versionen und zentrale Logs verwenden. Zugangsdaten niemals in öffentliche Repositories schreiben.
