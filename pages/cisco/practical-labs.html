Lab 01 – VLANs, 802.1Q-Trunk und Router-on-a-Stick

Ziel: Zwei VLANs über zwei Switches transportieren und Inter-VLAN-Routing mit einem Router bereitstellen.

1. Topologie und Verkabelung

PC-A (VLAN 10) -- SW1 Gi1/0/10
                       |
                  SW1 Gi1/0/48
                       |
                  SW2 Gi1/0/48
                       |
PC-B (VLAN 20) -- SW2 Gi1/0/10

R1 G0/0 -------- SW1 Gi1/0/47  (802.1Q-Trunk)

SW1 und SW2 sind über einen Trunk verbunden. R1 ist über einen zweiten Trunk an SW1 angeschlossen und übernimmt das Routing zwischen VLAN 10 und VLAN 20.

2. IP-Adressplan

GerätInterfaceAdresseGateway
PC-ANIC / VLAN 10192.168.10.10/24192.168.10.1
PC-BNIC / VLAN 20192.168.20.10/24192.168.20.1
R1G0/0.10192.168.10.1/24–
R1G0/0.20192.168.20.1/24–

Die Subinterfaces verwenden VLAN-Tags 10 und 20. Die Beispieladressen sind private IPv4-Adressen.

3. SW1 – vollständige Beispielkonfiguration

enable
configure terminal
hostname SW1

vlan 10
 name USERS
vlan 20
 name SERVERS

interface GigabitEthernet1/0/10
 description PC-A_VLAN10
 switchport mode access
 switchport access vlan 10
 spanning-tree portfast
 no shutdown

interface GigabitEthernet1/0/48
 description TRUNK_TO_SW2
 switchport mode trunk
 switchport trunk allowed vlan 10,20
 no shutdown

interface GigabitEthernet1/0/47
 description TRUNK_TO_R1
 switchport mode trunk
 switchport trunk allowed vlan 10,20
 no shutdown

end
show vlan brief
show interfaces trunk
copy running-config startup-config

Erklärung: VLANs 10 und 20 werden angelegt. PC-A erhält einen Access-Port in VLAN 10. Die Ports zu SW2 und R1 transportieren beide VLANs als Trunk.

4. SW2 – vollständige Beispielkonfiguration

enable
configure terminal
hostname SW2

vlan 10
 name USERS
vlan 20
 name SERVERS

interface GigabitEthernet1/0/10
 description PC-B_VLAN20
 switchport mode access
 switchport access vlan 20
 spanning-tree portfast
 no shutdown

interface GigabitEthernet1/0/48
 description TRUNK_TO_SW1
 switchport mode trunk
 switchport trunk allowed vlan 10,20
 no shutdown

end
show vlan brief
show interfaces trunk
copy running-config startup-config

Erklärung: PC-B wird VLAN 20 zugeordnet. Der Uplink zu SW1 transportiert VLAN 10 und VLAN 20.

5. R1 – Router-on-a-Stick

enable
configure terminal
hostname R1

interface GigabitEthernet0/0
 description TRUNK_TO_SW1
 no ip address
 no shutdown

interface GigabitEthernet0/0.10
 description GATEWAY_VLAN10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0

interface GigabitEthernet0/0.20
 description GATEWAY_VLAN20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0

end
show ip interface brief
show ip route connected
copy running-config startup-config

Erklärung: Das physische Interface bleibt ohne IP-Adresse. Jedes Subinterface erhält ein VLAN-Tag und die Gateway-IP des jeweiligen VLANs.

6. Endgeräte konfigurieren

PC-A statisch konfigurieren: IP 192.168.10.10, Maske 255.255.255.0, Gateway 192.168.10.1.

PC-B statisch konfigurieren: IP 192.168.20.10, Maske 255.255.255.0, Gateway 192.168.20.1.

7. Verifikation – Schritt für Schritt

! Auf beiden Switches:
show vlan brief
show interfaces trunk
show spanning-tree vlan 10
show spanning-tree vlan 20

! Auf R1:
show ip interface brief
show ip route connected

! Von PC-A:
ping 192.168.10.1
ping 192.168.20.10

! Von PC-B:
ping 192.168.20.1
ping 192.168.10.10

Erwartetes Ergebnis: Beide PCs erreichen ihr jeweiliges Gateway. Danach können sie sich über R1 gegenseitig erreichen, sofern lokale Host-Firewalls ICMP nicht blockieren.

8. Troubleshooting – typische Fehler

  • VLAN fehlt: show vlan brief prüfen und VLAN auf dem benötigten Switch anlegen.
  • VLAN nicht auf dem Trunk: show interfaces trunk prüfen; erlaubte VLAN-Liste auf beiden Seiten vergleichen.
  • Trunk kommt nicht hoch: Verkabelung, Interface-Status, Trunk-Modus und Gegenstelle kontrollieren.
  • Subinterface down: Physisches Router-Interface und Switchport prüfen.
  • Falsches Gateway: PC-IP, Maske und Gateway vergleichen.
  • Ping zum Gateway geht, PC-zu-PC nicht: Routingtabelle, Host-Firewall und ACLs prüfen.
show interfaces status
show interfaces trunk
show mac address-table dynamic
show ip interface brief
show ip route
show logging

9. Übungsaufgaben

  1. Erstelle zusätzlich VLAN 30 für Gäste.
  2. Erweitere beide Trunks um VLAN 30.
  3. Erstelle auf R1 das Subinterface G0/0.30 mit Gateway 192.168.30.1/24.
  4. Prüfe, ob ein Client in VLAN 30 sein Gateway erreicht.
  5. Erstelle anschließend eine ACL, die VLAN 30 den Zugriff auf VLAN 20 verbietet, aber den Zugriff auf ein erlaubtes Zielnetz ermöglicht.

Lernziel: VLAN-Erstellung, Trunking, 802.1Q, Inter-VLAN-Routing, ACL-Reihenfolge und systematische Verifikation sicher beherrschen.

Rollback im Lab: Bei Fehlkonfiguration die betroffenen Interfaces kontrolliert zurücksetzen oder die gespeicherte Lab-Konfiguration wiederherstellen. Auf Produktivgeräten niemals blind default interface oder globale Reset-Befehle ausführen.
