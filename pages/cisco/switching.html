Cisco Switching

VLAN · VTP · Trunk · STP · EtherChannel

VLAN

VLAN erstellen und Access-Port zuweisen

VLANs trennen ein Layer-2-Netz in eigene Broadcast-Domänen.

show vlan brief
configure terminal
vlan 10
 name CLIENTS
vlan 20
 name SERVERS
interface gigabitEthernet 1/0/10
 switchport mode access
 switchport access vlan 10
 spanning-tree portfast
end
show vlan brief

Prüfen: show interfaces gi1/0/10 switchport. Ein VLAN muss vorhanden und der Port dem richtigen VLAN zugeordnet sein.

VTP

VTP Version 1, 2 und 3

VersionMerkmale
VTP v1Grundlegende VLAN-Verteilung zwischen Switches derselben Domain.
VTP v2Erweiterte Behandlung bestimmter VLAN-Informationen und Konsistenzprüfungen.
VTP v3Unterstützt u. a. Extended VLANs und Private VLANs; Primary-Server-Konzept.

Modi: Server, Client, Transparent; VTP Off ist plattformabhängig. Domain, Version, Passwort und Trunk-Verbindungen müssen zusammenpassen.

show vtp status
show vtp counters
show vlan brief

! Lab-Beispiel VTP v3
configure terminal
vtp domain LABNET
vtp version 3
vtp mode server
vtp password CHANGE-ME
end
vtp primary vlan
show vtp status
VTP kann VLAN-Datenbanken unerwartet verändern. Gebrauchte Switches vor dem Anschluss isolieren und Domain sowie Configuration Revision prüfen. VTP v3 Primary nur bewusst vergeben. Syntax und Interoperabilität sind releaseabhängig.
Trunking

802.1Q Trunk konfigurieren

configure terminal
interface gigabitEthernet 1/0/48
 description Uplink-to-SW2
 switchport mode trunk
 switchport trunk allowed vlan 10,20,30
 switchport trunk native vlan 999
 no shutdown
end
show interfaces trunk
show interfaces gi1/0/48 switchport

Native VLAN und erlaubte VLANs auf beiden Enden abstimmen. VLAN 999 ist hier nur ein Beispiel für ein ungenutztes Native VLAN.

STP / RSTP

Spanning Tree konfigurieren

show spanning-tree
show spanning-tree summary
show spanning-tree vlan 10
show spanning-tree root

configure terminal
spanning-tree mode rapid-pvst
spanning-tree vlan 10 root primary
interface range gigabitEthernet 1/0/1-24
 spanning-tree portfast
 spanning-tree bpduguard enable
end
PortFast und BPDU Guard nur an geeigneten Endgeräte-Ports einsetzen, nicht auf Switch-Uplinks. Root-Bridge und Topologie vor Änderungen prüfen.
EtherChannel / LACP

Ports mit LACP bündeln

configure terminal
interface range gigabitEthernet 1/0/47-48
 channel-group 1 mode active
 no shutdown
interface port-channel 1
 switchport mode trunk
 switchport trunk allowed vlan 10,20,30
end
show etherchannel summary
show interfaces port-channel 1

Alle Member-Ports müssen kompatible Geschwindigkeit, Duplex-, VLAN- und Trunk-Einstellungen haben. LACP-Modi: active/passive.

Layer 2 Security

Port Security, DHCP Snooping und DAI

! Port Security auf einem Endgeräte-Port
interface gigabitEthernet 1/0/10
 switchport mode access
 switchport port-security
 switchport port-security maximum 2
 switchport port-security mac-address sticky
 switchport port-security violation restrict

! DHCP Snooping
ip dhcp snooping
ip dhcp snooping vlan 10,20
interface gigabitEthernet 1/0/48
 ip dhcp snooping trust

! Dynamic ARP Inspection
ip arp inspection vlan 10,20
interface gigabitEthernet 1/0/48
 ip arp inspection trust

Nur vertrauenswürdige Uplinks als trusted markieren. DAI benötigt passende DHCP-Snooping-Bindings oder ARP-ACLs für statische Hosts.

! SPAN-Beispiel

! Storm Control – Schwellenwert als Beispiel
interface gi1/0/10
 storm-control broadcast level 5.00
 storm-control action trap

SPAN-Zielports sind für die Analyse reserviert. Storm-Control-Schwellenwerte anhand des realen Verkehrs planen.
