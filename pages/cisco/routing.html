Cisco Routing

Static Routing · Inter-VLAN · OSPF · EIGRP

Grundlagen

Routing-Tabelle und Layer-3-Prüfung

show ip interface brief
show ip route
show ip route connected
show ip protocols
show arp
ping 192.168.1.1
traceroute 8.8.8.8

Prüfe zuerst Interface-Status, IP-Adresse, Subnetzmaske und Gateway. Danach Routing-Tabelle und Next Hop.

Static Routing

Statische Route konfigurieren

configure terminal
ip route 192.168.20.0 255.255.255.0 10.0.0.2
ip route 0.0.0.0 0.0.0.0 10.0.0.1
end
show ip route static

Die erste Route erreicht 192.168.20.0/24 über 10.0.0.2. Die zweite ist eine Default Route. Entfernen mit no ip route 192.168.20.0 255.255.255.0 10.0.0.2.

Inter-VLAN Routing

SVIs auf einem Layer-3-Switch

configure terminal
ip routing
vlan 10
vlan 20
interface vlan 10
 ip address 192.168.10.1 255.255.255.0
 no shutdown
interface vlan 20
 ip address 192.168.20.1 255.255.255.0
 no shutdown
end
show ip interface brief
show ip route connected

Clients nutzen die jeweilige SVI-Adresse als Default Gateway. Das SVI wird erst aktiv, wenn das VLAN existiert und ein aktiver Port darin vorhanden ist.

OSPF

OSPF Area 0 – Beispielkonfiguration

configure terminal
router ospf 10
 router-id 1.1.1.1
 network 10.0.0.0 0.0.0.3 area 0
 network 192.168.10.0 0.0.0.255 area 0
 passive-interface default
 no passive-interface gigabitEthernet 1/0/48
end
show ip ospf neighbor
show ip ospf interface brief
show ip route ospf
show ip protocols

OSPF-Nachbarn benötigen passende Area-, Timer-, MTU- und Authentifizierungseinstellungen. Wildcard 0.0.0.255 entspricht /24.

EIGRP

EIGRP – klassischer Named/AS-Kontext

configure terminal
router eigrp 100
 network 10.0.0.0 0.0.0.3
 network 192.168.10.0 0.0.0.255
 passive-interface default
 no passive-interface gigabitEthernet 1/0/48
end
show ip eigrp neighbors
show ip eigrp topology
show ip route eigrp
EIGRP-Unterstützung und klassische Syntax sind modell-, lizenz- und releaseabhängig. Nicht jeder Catalyst-Switch unterstützt EIGRP.
DHCP Relay

DHCP-Requests an zentralen Server weiterleiten

configure terminal
interface vlan 10
 ip helper-address 192.168.100.10
end
show running-config interface vlan 10

ip helper-address wird auf dem Client-Gateway/SVI gesetzt und leitet DHCP-Broadcasts an den DHCP-Server weiter. Routing und Firewall-Regeln müssen den Rückweg erlauben.

BGP – Grundlagen

BGP-Nachbarschaften und Routen prüfen

BGP wird häufig zwischen autonomen Systemen eingesetzt. Vor Änderungen AS-Nummern, Neighbor-IP, Update-Source, Policies und Prefix-Filter prüfen.

show ip bgp summary
show ip bgp
show ip bgp neighbors
show ip route bgp
show ip protocols
BGP-Konfiguration ist stark abhängig von Plattform, IOS/IOS XE-Version und Design. Prefix-Listen, Route-Maps und maximale Prefix-Anzahl vor produktiver Aktivierung planen.
Routing-Diagnose

Route-Entscheidung nachvollziehen

Prüfen, ob Zielnetz bekannt ist, welcher Next Hop gewählt wurde und ob die Ausgangsschnittstelle erreichbar ist.

show ip route <DESTINATION-IP>
show ip cef <DESTINATION-IP>
show ip arp
traceroute <DESTINATION-IP>
ping <DESTINATION-IP> source <SOURCE-INTERFACE>
CEF- und Source-Ping-Syntax kann je nach Plattform variieren. Rückweg, ACLs und VRF-Zuordnung ebenfalls prüfen.
